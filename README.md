# Talkza: Product Verification Pack

Talkza is a private, end-to-end encrypted messenger. Sign up with a username only, no phone number. Live web app: https://talkza-beta.vercel.app

This repository holds **evidence and documentation only**. It contains no source code, no front-end or back-end code, no keys and no real user data.

## How to read this pack
Every claim uses one of these labels. A feature is called **Verified** only if a test in [test-results/](test-results/README.md) backs it.

| Label | Meaning |
|---|---|
| Verified | Tested and seen working, with a record in `test-results/` |
| Verified by owner | Tested by hand by the owner on real devices; recorded here, not watched by the assistant |
| Built | Written and deployed, not yet tested end to end |
| Needs real devices | Can only be shown on real phones, not yet tested |
| Planned | Not built |
