## Safety and smart tools
Scam check for new contacts, chat summary, before-you-share check, tone check, evidence log, business leads, expense split, shopping list, saved messages, notes and lists, snippets, important dates, storage cleaner, emergency lock, link scanner. All **Verified**. They run on the device.

## Business (Hungry Hours connection)
| Feature | Status |
|---|---|
| Connect a restaurant's Hungry Hours profile with a one-time token | Verified (T4) |
| Deals arrive as a card with the restaurant logo and a "View deal" button | Verified (T5) |
| Menu imported into the business profile | Verified |
| Deals sent automatically to one-to-one chats, no daily limit | Verified |
| Optional: also post each deal to the owner's Status | Verified (T9) |

Limit: deals send only while Talkza is open on the owner's device, because messages are encrypted on that device.

## Premium
Some tools show a "Go to Talkza Premium" prompt (owner reports it works, O4). The code does not process payments, so no payments were tested.
